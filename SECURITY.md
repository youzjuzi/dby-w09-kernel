# Security

This source repository contains kernel patches, board configuration and host extraction/build tools. Security-sensitive problems include unsafe kernel behaviour, bypassed input verification and disclosure of owner data through generated files or diagnostics.

Maintenance targets the current development branch/current commit only. There are no release/tag support commitments or supported release series; fixes may require updating to the current development commit.

Submit sensitive reports through GitHub private vulnerability reporting. The maintainer will enable and test that facility before the repository becomes public; this document does not claim that it is enabled or tested now. Do not place vulnerability details or owner data in a public issue. If the private reporting entry is unavailable, wait for its activation rather than disclosing sensitive details publicly.

通过 GitHub 私密漏洞报告提交安全问题；维护者会在公开前启用并测试该功能。当前支持范围仅为开发分支／当前提交，没有 release/tag 支持承诺。
